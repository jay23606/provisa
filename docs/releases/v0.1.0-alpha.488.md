# v0.1.0-alpha.488

Released 2026-10-15.

## Features

### Table Registration

- A TTL of -1 means never expires: the table lands once and its replica is never stale after that. -1 can be set on a source, which its tables inherit as they inherit any TTL, or on a table.
    - -1 never expires
